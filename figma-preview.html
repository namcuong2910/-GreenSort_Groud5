3 Bước Nhanh Để Có Link Figma Thật 100%

Bước 1
Mở Figma

Truy cập figma.com, đăng nhập tài khoản của bạn và tạo 1 file nháp mới (New design file).

Bước 2
Dùng Plugin Chuyển HTML

Trong Figma, vào mục Plugins -> tìm plugin miễn phí "html.to.design" -> Dán đường dẫn hoặc import file resident-waste-guide.html vào. Figma sẽ tự vẽ toàn bộ Layer, Frame và Auto Layout!

Bước 3
Lấy Link Nộp Bài

Bấm nút Share góc phải trên cùng -> Bật chọn "Anyone with the link can view" -> Copy link và dán vào mục 2 của file README.md.

Khi quay video OBS 3 phút: Bạn chỉ cần mở trang figma-preview.html này lên, chiếu tab Bản Thiết Kế & Design Tokens là đã đủ minh chứng trực quan hoàn hảo cho 1.5 điểm Figma theo yêu cầu của thầy giáo!
